2.5D Spheroid
=============

Exploit spherical geometry to calculate the three-dimensional (3D) traction forces of multicellular spheroids or organoids from two-dimensional (2D) time-lapse image series.

Example data sets for this module are available from the graphical user interface,
under `add measurement` → `Load Example`.
